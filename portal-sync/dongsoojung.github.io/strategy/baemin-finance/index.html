전략 시사점

성장은 유지, 수익성은 정상화2024년 매출은 크게 늘었지만 영업이익률은 2023년 고점에서 하락했습니다. 쿠폰·무료배달·물류 경쟁 비용이 수익성 관리의 핵심 변수입니다.
아시아 GMV와 매출의 방향이 다름Delivery Hero 아시아 GMV는 감소했지만 세그먼트 매출은 증가했습니다. 거래액 확대보다 광고·구독·수수료 등 수익화 효율이 중요해진 신호입니다.
다음 KPI는 주문보다 단위경제성주문건수, 객단가, 배달비 보조, 광고 매출, 라이더 비용을 함께 추적해야 성장의 질을 판단할 수 있습니다.
데이터 범위와 출처
우아한형제들 재무는 공개 기업정보에 표시된 감사보고서 기반 수치를 정리했습니다. Delivery Hero KPI는 공식 FY 2024·FY 2025 실적 발표 기준입니다. 우아한형제들 단독 재무와 Delivery Hero 아시아 세그먼트는 연결 범위가 다르며, 아시아 수치에는 한국 외 시장이 포함됩니다. 자동 API 연동 시 OpenDART 기업코드·사업보고서 API와 Delivery Hero IR JSON 변환 파이프라인을 연결하도록 설계할 수 있습니다.
