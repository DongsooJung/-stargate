# Play Console 데이터 보안 답안 — Stargate

앱: `kr.co.stargateedu.app` · TWA · https://stargateedu.co.kr/

수업 예약 폼이 이름·연락처를 받을 수 있으므로 **수집함**으로 작성합니다.
(포털 루트 `privacy.html`의 “수집하지 않음”과 다르므로, Play 방침 URL은
`https://stargateedu.co.kr/-stargate/privacy.html` 을 사용하세요.)

## 개요 질문

| 질문 | 답 |
|------|-----|
| 사용자 데이터를 수집·공유합니까? | **예** (예약 시) |
| 데이터를 제3자에게 판매합니까? | **아니요** |
| 데이터 삭제 요청을 처리합니까? | **예** |
| 전송 중 암호화? | **예** (HTTPS) |
| 사용자가 계정을 만들 수 있습니까? | **아니요** |

## 수집하는 데이터 유형

### 개인 정보
- **이름** — 수집됨, 공유 안 함, 앱 기능(수업 예약), 선택 입력
- **전화번호** — 수집됨, 공유 안 함, 앱 기능(예약 본인 확인), 선택 입력
- **이메일 주소** — 수집됨(입력한 경우), 공유 안 함, 앱 기능(알림), 선택 입력

### 수집하지 않음
위치, 사진, 연락처 목록, 오디오, 건강, 금융, 앱 활동 분석, 기기 ID, 광고 ID

## 처리자
Supabase는 Google 분류상 **서비스 제공업체**(위탁 처리)입니다. “데이터 공유”의 제3자 판매/광고 네트워크가 아닙니다.

`ceo@stargateedu.co.kr` 로 요청 시 예약·출결 기록을 삭제합니다.
